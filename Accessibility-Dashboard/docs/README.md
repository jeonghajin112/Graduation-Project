# 프런트 문서

설치와 실행은 [README](../README.md), 프런트 작업 방식은 [GPT-6 Astra 개발 기준](engineering.md)을 따른다.

| 문서 | 답하는 질문 |
|---|---|
| [아키텍처](architecture.md) | 상태는 누가 소유하고 어떤 계약을 지켜야 하는가? |
| [테스트 가이드](testing.md) | 이번 변경에 어떤 검사를 실행해야 하는가? |
| [디자인 시스템](design-system.md) | 기존 UI와 접근성 동작을 어떻게 이어갈 것인가? |
| [개발 기준](engineering.md) | 어디까지 공통화하고 어떤 근거로 설계를 바꿀 것인가? |

함수·상수·테스트 목록 전체를 문서에 복사하지 않는다. 코드를 가리키고 설계 이유와 사용 방법을 설명한다. 문서의 기대 동작과 실제 결함은 구분한다. 현재 확인된 프런트 오류와 완료 기준은 아키텍처 문서에 둔다.

임시 로그와 캡처는 Git에서 제외되는 `artifacts/`에 둔다.
